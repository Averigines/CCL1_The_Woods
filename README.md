A very short plain JavaScript browser game which I've done for the first term of my bachelor studies 'Creative Computing'.

## Setup

1. Clone the repository:
   ```sh
    git clone https://github.com/Averigines/The-Woods.git
    ```

2. Navigate to the project folder:
   ```sh
    cd yourlocation
    ```

3. Start a local server (e.g. [LiveServer](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) on vscode)
   
4. Open your browser and go to:
   ```sh
   http://localhost:[port]
   ```

## How to Play

* Use the arrow keys to move
* Use the spacebar to jump
* Avoid enemies until the moon sets
